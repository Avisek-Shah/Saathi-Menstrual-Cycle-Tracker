# Saathi

An offline-first, private period tracker for Android.

## Installation

Since Saathi is distributed privately, you will install it directly (sideloading) rather than from the Play Store.

1. Tap the download link you were given and download the `.apk` file.
2. Your phone will ask for permission to install from your browser or file manager. Allow it.
3. You may see a warning saying the app is unknown. Tap "Install anyway" — this appears for any app not downloaded from the Play Store.
4. Open the app and answer the four questions to get started.

**Your information stays only on your phone.** It is not sent anywhere, and nobody — including the developer — can see it.
